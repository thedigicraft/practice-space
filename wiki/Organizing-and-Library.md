# Organizing & Library

## Folders (Slice Browser)
- Navigate with breadcrumbs
- Drag and drop slices between folders
- Use the selection toolbar for batch actions: select all, clear, export, delete

## Library View
- Slices grouped by type and title
- Click a group to view grouped slices
- Location badges show where slices originated

## Filtering
- Filter sources by search, location, sort (title, name, duration, size, imported)
- Quick-filter by clicking tags (artist/type/location) where available
