## Overview
Practice Space is a local-first, offline-capable Vue 3 application. It uses modern browser APIs (File System Access, Web Audio, IndexedDB, Web Workers) to keep your audio and metadata on your device.

- No backend — privacy-first
- Non-destructive slices — originals are never modified
- Fast waveform visualization in Web Workers
- Organized library with folders and grouping
