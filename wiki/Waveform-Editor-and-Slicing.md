# Waveform Editor & Slicing

## Open a Source
- From Home or Sources, click a source to open the editor
- The waveform viewer renders downsampled peaks for responsive navigation

## Region Selection
- Click and drag on the waveform to select a time range
- Fine-tune start/end by dragging handles
- Use keyboard arrows to nudge selection

## Create a Slice
- After selecting a region, use the toolbar to create a slice
- Fill metadata: title, composer, performer, type (song, etude, scale, exercise, warm-up, technique), tags, notes
- Slices reference the source — originals are never modified

## Playback
- Play/pause the selected region
- Seek quickly via keyboard shortcuts (see Keyboard Shortcuts)

## Editing Metadata Inline
- Double-click titles (where supported) to edit inline
- Save changes to update the source or slice metadata
