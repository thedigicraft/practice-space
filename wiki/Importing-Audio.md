# Importing Audio

## Import Methods
- Use the Import Controls to select files or entire folders
- Grant permission once; the app remembers handles

## Supported Formats
- Depends on the browser's Web Audio support
- Common: WAV, MP3, AAC, OGG (varies by platform)

## Locations
- Sources include an optional `location` field (e.g., folder name)
- Click a location tag to filter anywhere locations are shown

## Tips
- Keep long recordings; slicing is non-destructive
- If permission is denied or revoked, re-import or re-authorize in browser dialogs
